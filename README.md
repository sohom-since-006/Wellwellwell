## 📑 Core Repository Architecture

```text
Wellwellwell/
├── ⚡ algorithms/
│   ├── bitwise/          # Kernighan, bitmasks, bit reversal, single number
│   ├── dp/               # 0/1 Knapsack, LCS, Coin Change, Kadane
│   ├── math/             # Sieve, GCD/LCM, Modular Exponentiation, Factorization
│   ├── recursion/        # Tower of Hanoi, N-Queens, Permutations
│   ├── searching/        # Binary, Ternary, Jump, Exponential Search
│   ├── sorting/          # Bubble, Selection, Insertion, Merge, Quick, Heap, Radix
│   └── strings/          # Palindrome, Anagram, Caesar, RLE, Rabin-Karp
├── 🧱 data_structures/
│   ├── graphs/           # Adjacency Matrix, BFS, DFS
│   ├── linked_list/      # Singly, Doubly, Circular Linked Lists
│   ├── queue/            # Linear Queue, Circular Queue, Deque, Priority Queue
│   ├── stack/            # Array Stack, Linked Stack, Infix to Postfix, Evaluator
│   └── trees/            # Binary Search Tree, Traversals, Height/Metrics, Deletion
├── 🛠️ scripts/
│   ├── build_all.ps1     # Automated batch compilation
│   └── run_tests.py      # Automated invariant verification tests
└── 📖 docs/
    ├── COMPLEXITY_GUIDE.md # Detailed Big-O analysis & bitwise invariants
    └── DSA_CATALOG.md      # Full catalog of algorithms & data structures
```

## 🛠️ How to Compile & Run

```bash
# Compile and test core DSA programs:
make dsa

# Run the test suite:
python scripts/run_tests.py

# Batch compile all laboratory files in PowerShell:
pwsh scripts/build_all.ps1
```
