# 📚 Complete Data Structures & Algorithms Catalog

Comprehensive catalog of all algorithms and data structures implemented in this laboratory.

## 1. Sorting Algorithms
- **Bubble Sort**: $\mathcal{O}(n^2)$ time, in-place, early-exit optimization.
- **Selection Sort**: $\mathcal{O}(n^2)$ time, minimal swaps.
- **Insertion Sort**: $\mathcal{O}(n)$ best case for nearly-sorted inputs.
- **Merge Sort**: $\mathcal{O}(n \log n)$ time, stable, divide-and-conquer.
- **Quick Sort**: $\mathcal{O}(n \log n)$ average time, cache-efficient in-place.
- **Heap Sort**: $\mathcal{O}(n \log n)$ guaranteed time using binary heapify.
- **Counting Sort**: $\mathcal{O}(n + k)$ non-comparison integer sorting.
- **Radix Sort**: $\mathcal{O}(d \cdot (n + b))$ LSD digit-distribution sort.

## 2. Searching Algorithms
- **Binary Search**: $\mathcal{O}(\log n)$ on sorted array.
- **Ternary Search**: $\mathcal{O}(\log_3 n)$ unimodal peak / search.
- **Jump Search**: $\mathcal{O}(\sqrt{n})$ block jumping.
- **Exponential Search**: $\mathcal{O}(\log n)$ unbounded arrays.

## 3. Linear Data Structures
- **Singly / Doubly / Circular Linked Lists**
- **Stacks**: Array Stack, Linked Stack, Postfix Evaluation, Infix Converter.
- **Queues**: Linear Queue, Circular Ring Queue, Deque, Priority Queue.

## 4. Trees & Graphs
- **Binary Search Tree (BST)**: Insertion, Search, Deletion, Node counting.
- **Traversals**: Preorder, Inorder, Postorder, Level-Order (BFS).
- **Graphs**: Adjacency Matrix, Breadth-First Search (BFS), Depth-First Search (DFS).
